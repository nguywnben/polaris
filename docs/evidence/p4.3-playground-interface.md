# P4.3 — Playground Interface

Date: 2026-09-10
Plan: `PROD-SELFHOST-R1`
Status: complete

## Result

Polaris now has a first-class `/playground` console page for exercising the real P4.2
Playground boundary without installing or configuring an external client. The page supports
OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Google GenAI from one normalized,
bounded message draft while preserving each protocol's native request and response shape.

The workflow includes model and protocol selection, optional system instructions, a 32-message
editor, streaming, a 1–120 second deadline, maximum output tokens, temperature, Top P, cancel,
native error output, route/usage/quality/compression metadata, and a direct link to AI Quality.
Models & Routing can hand a validated model to the page through the existing one-use, secret-free
handoff.

## Bounds and Privacy

- The editor allows at most 32 non-empty messages, 65,536 characters per message or system
  instruction, and 524,288 total text characters. Invalid requests stop locally.
- Displayed response data is capped at 2 MiB by received byte count. Crossing the limit cancels the
  reader and the in-flight backend request.
- One `AbortController` owns the active run; controls that could mutate its draft are disabled until
  it completes or is cancelled.
- Prompt and response history live only in JavaScript memory. Nothing writes them to local or
  session storage; refresh or close clears them. Session storage is read only to consume and remove
  the bounded Models handoff.
- Model output, stream frames, native errors, and metadata are inserted with text nodes. No output
  path uses `innerHTML`.
- Generated cURL and Python SDK examples always contain `<YOUR_POLARIS_KEY>` and never copy the
  console session, root key, or a stored provider credential. Gemini SDK examples preserve system
  instructions and generation parameters through `GenerateContentConfig`.

## Interaction and Localization

The page is part of the primary navigation and has a responsive two-column composer/results layout
that collapses to one column at 860 px. All controls have visible labels, native keyboard behavior,
focusable alerts, polite status regions, and reduced-width layouts without horizontal scrolling.

English and Vietnamese have curated production copy. Other supported locales receive the complete
English fallback. Dynamic message roles, labels, protocol hints, run state, outcome, and generated
examples refresh when the active locale changes rather than retaining stale text.

## Verification

- RED first: six focused tests initially failed because the page, registration, styles, and browser
  helper did not exist.
- Browser contract: authenticated Chrome loaded the real assembled console and passed deterministic
  success, native stream, native error, user cancellation, and hostile HTML-output fixtures. The
  XSS payload remained inert text; dynamic English/Vietnamese state switched correctly; 1440 px
  and 360 px had no horizontal overflow; no runtime exception was recorded.
- Runtime: after removing a stale duplicate listener, exactly one current-checkout process served
  `/ready`, `/dashboard`, `/playground`, and `/ai-quality` with HTTP 200. The duplicate listener was
  the reason an early smoke request alternated between the old route table and the current bundle.
- Final fixed task gate: Ruff lint/format for 439 Python files, compilation, the 194-Core/
  13-experimental partition, recursive JavaScript syntax, strict YAML, six shell checks,
  whitespace, and **68 affected tests** all passed. The first sandboxed gate stopped only at the
  known Windows Git Bash signal-pipe error 5; the identical approved run passed outside sandbox.

## Review and Scope Balance

The final review covered correctness, compatibility, accessibility, security/privacy, performance,
test readiness, and maintainability. It changed the display ceiling from character counting to byte
counting with request abort, throttled growing stream paints to 20 per second, rejected blank
assistant messages, corrected Google SDK example mapping, preserved dynamic state across locale
changes, and exposed a browser-only state-scope bug before closure. No dependency, data schema,
public inference route, credential behavior, or new background service was added.
