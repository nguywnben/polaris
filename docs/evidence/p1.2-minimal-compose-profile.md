# P1.2 — Minimal Canonical Docker Compose Profile

Date: 2026-09-08
Plan: `PROD-SELFHOST-R1`

## Result

The canonical Compose path now starts a supported standalone deployment without PostgreSQL,
MongoDB, or Redis. The default surface contains only authentication bootstrap, listener, fixed
single-process topology, log level, and host-port controls. Optional identity, external storage,
proxy, routing, cache, guardrail, and telemetry controls live in `deploy/compose.advanced.yml`.

The application data directory is stored in the stable `polaris-data` named volume by
default. The service retains its read-only root filesystem, `no-new-privileges`, init process,
bounded Docker logs, storage-aware readiness check, 45-second shutdown allowance, and
`unless-stopped` restart policy. Runtime secrets are supplied only through Compose interpolation;
the image has no secret build arguments or secret environment values.

CI now exercises the same canonical Compose file used by operators. It initializes a fresh
instance, force-recreates the container, verifies the existing setup can still authenticate, then
performs a graceful stop and deletes only the isolated CI volume.
