# P0.1 Evidence — Capability Registry and Support Tiers

## Result

P0.1 is complete. Polaris now has one immutable, versioned product-capability contract and an
authenticated read-only API at `GET /api/capabilities`.

## Delivered Contract

- Schema version: `1`
- Product profile: `self_hosted`
- Stable support tiers: `core`, `advanced`, `compatibility`, `experimental`
- Stable runtime states: `active`, `available`, `disabled`, `blocked`
- Default inventory: 31 capabilities
  - 19 Core
  - 6 Advanced
  - 3 Compatibility
  - 3 Experimental
- Default state projection:
  - 12 active, all Core
  - 13 available
  - 4 disabled
  - 2 blocked

The registry covers runtime topology, storage backends, local/OIDC identity, telemetry exporters,
deployment assets, public protocols, provider families, routing, quality, access, and activity.
Provider families are derived from the existing provider registry rather than duplicated.

## Safety Properties

- The endpoint uses the existing panel-token dependency and `configuration.read` permission.
- The response contains controlled metadata only; environment values and secrets are never returned.
- Conflicting PostgreSQL and MongoDB selection reports all storage choices as blocked rather than
  falsely reporting SQLite active.
- Coordinated and multiple-replica runtime remain blocked because this build has no accepted HA
  activation record.
- The change is additive and does not alter an existing public inference or management response.
- No dependency was added.

## Review

- Correctness: versioned typed response, deterministic ordering, unique IDs, boundary and conflict
  tests.
- Readability: one declarative registry module and one thin route; no configuration side effects.
- Architecture: provider metadata reuses the canonical provider registry; authorization reuses the
  exact management-route manifest.
- Security: authenticated least-privilege GET, no secret projection, no input or external I/O.
- Performance: bounded 31-item in-memory projection with no database or network access.

Verdict: approved for the production self-hosted baseline.
