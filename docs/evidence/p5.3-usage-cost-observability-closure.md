## Pricing Contract

- Known models use the longest matching reviewed price entry.
- A local/self-hosted zero-cost provider remains explicitly classified, rather than inferred from
  an unknown model.
- Hard budgets never admit unknown pricing as zero. `deny` rejects; `warn` warns and rejects;
  `fallback` requires a positive bounded price and reserves against it.
- Positive sub-nano-dollar fractions round up instead of silently becoming zero in the integer
  ledger contract.
- Pricing freshness metadata contains no credentials-directory path. Operators can compare the
  review/update timestamps with current provider billing and hot-reload `model_pricing.json`.

## Bounded Correlation and Retention

- Request traces store a bounded request ID, canonical protocol/outcome, model/provider, numeric
  usage/cost, and at most 64 allowlisted decisions. Unknown fields and free-text reasons fail
  closed; prompts, response bodies, authorization values, API keys, and secrets are absent.
- The same request ID supports trace/audit/usage correlation without becoming a Prometheus or OTLP
  label. Operational snapshots deliberately remove individual request and trace IDs.
- Request-trace and audit retention policies are separate, strictly decoded, capped, persist before
  pruning, and use amortized/bounded prune work. Failed persistence does not silently activate a
  new policy.
- Prometheus provider labels collapse unknown values to `other`; RED, quota, coordination,
  identity, routing, storage, and Playground dimensions use closed vocabularies.

## Exporter-Off Assertion

- Prometheus requires explicit enablement plus a bearer token of at least 32 UTF-8 bytes and
  returns 404 while disabled. It is a pull endpoint and makes no outbound connection.
- The OTLP function checks `otel_enabled` before collecting a snapshot or constructing its HTTP
  client. The new direct mock assertion proves zero client construction while disabled.
- The Langfuse completion task resolves configuration, then returns before constructing
  `TelemetryExporter` when either required key is absent. The new direct assertion proves that
  boundary. When enabled, existing tests prove exported input/output bodies are `None` and metadata
  is allowlisted.
