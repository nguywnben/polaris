Verify those fixes rather than trusting them. Report findings first, ordered Critical/High/Medium/
Low, with exact file and line references, exploit/failure scenario, and the smallest safe fix. Mark
uncertain claims explicitly. Then list residual risks, missing tests, and a final PASS / PASS WITH
CONDITIONS / FAIL recommendation. If no actionable issue exists, say so plainly and describe what
you inspected.
